# CostGraph Helm charts

Helm charts for running CostGraph on Kubernetes.

```sh
helm repo add costgraph https://charts.costgraph.ai
helm repo update
helm install <name> costgraph/<chart> -f my-values.yaml
```

## Which chart do I need?

| Chart | Install it when |
|---|---|
| [costgraph-selfhosted](charts/costgraph-selfhosted) | You run CostGraph itself on your own infrastructure|
| [costgraph-operator](charts/costgraph-operator) | You use CostGraph (hosted or self-hosted) and want Costgraph's kubernetes support |
| [focus-exporter](charts/focus-exporter) | You want CostGraph to see a bill it cannot reach itself, read where it lives and pushed from your own cluster |
| [costgraph](charts/costgraph) | **Deprecated.** The single-binary operator, broken out into the domain-specific operators above. New installs should use `costgraph-selfhosted`. |

Most self-hosted customers install two: `costgraph-selfhosted` once, then
`costgraph-operator` in every cluster they want to see costs for. Customers on
hosted CostGraph install only `costgraph-operator`.

Each chart's README covers what it needs and how to configure it, and
`values.yaml` documents every setting inline:

```sh
helm show values costgraph/costgraph-selfhosted
```

## Trying a chart before installing it

Render the manifests and check them against your cluster without creating
anything:

```sh
helm template costgraph costgraph/costgraph-selfhosted -f my-values.yaml \
  | kubectl apply --dry-run=client -f -
```

## Contributing

`values.yaml` is the reference customers read, so keep comments there
describing what a setting does and when to change it.

Charts are versioned and released independently; see
[RELEASING.md](./RELEASING.md).

Chart READMEs are generated by [helm-docs](https://github.com/norwoodj/helm-docs)
on every pull request. Where a chart has a `README.md.gotmpl`, edit that file —
editing its `README.md` directly is overwritten on the next run.

Diagrams:

```sh
pip install KubeDiagrams
helm-diagrams ./charts/costgraph-operator
mv costgraph-operator.png ./images/diagram.png
```
